# 尖塔排表

**在线使用：[打开尖塔排表（GitHub Pages）](https://yelllicator.github.io/sts2tierlist/)**

杀戮尖塔 2 卡牌排表工具。支持八套独立模板、双语卡面、版本切换、PNG 导出、JSON 方案备份，以及浏览器内截图识别和 OCR。

新工作区默认使用测试版 0.113.0，收录 716 张卡和新职业愚者，各评级为空。另有独立的遗物排表，收录 0.113.0 的 315 件遗物，支持版本切换、本地保存、JSON 导入导出及 PNG 导出。游戏规则随站点提供固定快照。

每次打开或刷新卡牌页、遗物页时，工作区使用站内最新游戏版本，保留已有排位与卡池删减，不自动补入新卡或遗物。页面打开后仍可切换旧版、按保存版本载入方案或 JSON；再次刷新后使用最新版本。

## 使用

打开本仓的 GitHub Pages 网站。排表保存在当前浏览器来源的 localStorage / IndexedDB；切换来源或设备时，通过方案库导出和导入 JSON。没有云同步。截图识别在浏览器 Worker 内完成，不上传截图。

## 当前功能

- [遗物排表](https://yelllicator.github.io/sts2tierlist/relics.html)可在 0.113.0 与 0.111.0 之间切换。
- 待排区和选择卡牌窗口支持类型及费用多选，可搜索中英文牌名、卡片说明和关键词。
- 卡牌和遗物的 PNG 导出在标题栏右侧带有网站二维码。
- 支持跨版本选牌，同一卡牌的不同版本可同时排入，版本外卡牌明确标记。
- 待排队列支持连续滚动、折叠、拖放定位与撤回跳过。当前模板可一键清空评级并撤销。
- 截图导入支持批量核对。生成时保留重复卡首次出现的位置，界面会提示跳过的未识别项。

## 检查与部署

需要 Node.js 18 或以上版本；运行 `npm test` 检查资源、公开内容、默认状态和旧方案兼容。无需安装 npm 依赖或构建卡图。

在仓库 Settings → Pages 将 Source 设为 GitHub Actions。main 分支更新后，工作流检查通过才会发布 dist；也可在 Actions 手动运行 main 分支的 Deploy GitHub Pages。

本仓是可独立发布的静态快照。来源、游戏资产归属与 OCR 许可证见 [SOURCES.md](SOURCES.md)。
